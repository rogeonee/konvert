# **Konvert** – Minimalist Client-Side Image Converter  

🚀 **[Try it live](https://www.knvrt.one/)**  

Konvert is a **browser-based image format converter** with a **Vercel-inspired design**. Built for speed, privacy, and simplicity, all conversions happen client-side – no uploads, no servers.

## **Features**  
- **HEIC, WebP & AVIF → JPG/PNG** conversion  
- **Client-side only** – no backend, no data leaves your device  
- **Batch processing** – convert multiple images at once  
- **Mobile-friendly & PWA-ready** – works across all devices  
- **Minimalist UI** – smooth animations, clean design  

## **Tech Stack**  
- **Next.js** + **React** – frontend & routing  
- **Tailwind CSS** + **shadcn/ui** – UI components & styling  
- **libheif-js** – HEIC decoding  
- **Web Workers** – offload conversions for better performance  
- **Vercel** – hosting & deployment  

## **Setup & Run Locally**  
```bash
git clone https://github.com/rogeonee/konvert.git
cd konvert
npm install
npm run dev
```
